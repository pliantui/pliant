Pliant is open source, developed in public on [GitHub](https://github.com/pliantui/pliant). Here's how it's licensed, how to take part, and what it's built with.

## License

Pliant is free and open source under the [MIT License](https://github.com/pliantui/pliant/blob/main/LICENSE.md). You can use it in commercial and closed-source apps.

The components you copy into your project are yours to change, like any shadcn component.

## Get involved

Questions and ideas are welcome as [issues on GitHub](https://github.com/pliantui/pliant/issues). To contribute code or docs, start with [CONTRIBUTING.md](https://github.com/pliantui/pliant/blob/main/CONTRIBUTING.md), which covers setting up the repository and opening a pull request. Please report security problems privately, as [SECURITY.md](https://github.com/pliantui/pliant/blob/main/SECURITY.md) describes, rather than in a public issue. What's planned next is on the [roadmap](/docs/roadmap).

## Built on

Pliant is built with these open-source projects:

| Project                                                      | What Pliant uses it for                                                                            |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| [shadcn/ui](https://ui.shadcn.com)                           | The components Pliant's own render, the registry and CLI they install with, and this site's design |
| [TanStack Table](https://tanstack.com/table)                 | Editable tables                                                                                    |
| [Zod](https://zod.dev)                                       | Checking every change before it applies                                                            |
| [Vercel AI SDK](https://ai-sdk.dev)                          | Talking to the model behind the ask panel                                                          |
| [Radix UI](https://www.radix-ui.com)                         | Accessible primitives in the ask panel and point mode                                              |
| [Lucide](https://lucide.dev)                                 | Icons                                                                                              |
| [React](https://react.dev) and [Next.js](https://nextjs.org) | The runtime, and this site                                                                         |
| [Fumadocs](https://fumadocs.dev)                             | These docs                                                                                         |

## Ideas it builds on

The idea that people should be able to reshape the software they use is much older than Pliant. [Why Pliant](/docs/why#earlier-work) credits the work it draws on, from Smalltalk and HyperCard to Ink & Switch's essay on malleable software.

The docs follow [Diátaxis](https://diataxis.fr), the [Google developer documentation style guide](https://developers.google.com/style) and the [Write the Docs](https://www.writethedocs.org) community's guidance.
