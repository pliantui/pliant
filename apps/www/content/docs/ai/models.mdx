The ask route works with any language model the [AI SDK](https://ai-sdk.dev) supports: Anthropic, OpenAI, Google, Mistral, models on your own servers, and more. Pass the model to `createPliantHandler`:

  snippets/ai/route.ts#route
</include>

To use another provider, install its AI SDK package, such as `@ai-sdk/openai`, and pass one of its models. Pass a model instance, not a model id string.

## What makes a good model for asks

Asks are short, and answers are a few small tool calls, so you don't need a large model. Look for:

- reliable tool calling, because every answer is a set of tool calls with a fixed shape;
- low latency, because users wait for the preview;
- a low price per request, since each ask is one or two short requests.

Small, fast models from the major providers handle most asks well. Try yours on your own pages with [`pliantui eval`](/docs/ai/eval).

## Every model's answers are checked the same way

Every answer is checked against the same catalog, the same capabilities and the same guardrails, whichever model wrote it. A weaker model gets more answers wrong or asks for clarification more often, but it can't make a change those checks reject. An answer that fails the check gets one retry, then an error.

## Recommended models

  Pliant yet. Today, you pass one model to `createPliantHandler`.

Pliant publishes a list of recommended models that pass its eval suite, checked again on every release. `pliantui doctor` warns when your model isn't on the list and you haven't evaluated it yourself.

You can also give a fallback, used when the first model fails or times out:

```ts
model: { primary: anthropic("claude-haiku-5-5"), fallback: anthropic("claude-sonnet-5-5") },
```
