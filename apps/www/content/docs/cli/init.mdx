Use the `init` command to add Pliant to a Next.js App Router project that already uses shadcn/ui.

<Callout

  `npx pliantui` and `npm install` commands on this page work only inside the
  Pliant repository.

<Steps>

<Step>Install the React package</Step>

```bash
npm install @pliantui/react zod
```

<Step>Add the region component</Step>

```bash
npx shadcn@latest add https://pliantui.dev/r/pliant-region.json
```

</Steps>

The command installs the `@pliantui/react` package with your package manager, found from your lockfile or, without one, the `packageManager` field in `package.json` (pnpm, npm, yarn or bun), and adds the `pliant-region` component to your project with `shadcn add`. It asks before each step and shows the command it will run. If you answer no, it prints that command so you can run it yourself.

When it's done, your project has the package in `package.json` and the component in your components folder:

<FileTree>
  <Folder name="components">
    <Folder name="pliant">
      <File name="pliant-region.tsx" />
    </Folder>
  </Folder>
  <File name="package.json" />
</FileTree>

```txt
Usage: pliantui init [options]

add Pliant to your Next.js and shadcn project

Options:
  -y, --yes             skip confirmation prompts. (default: false)
  -c, --cwd <cwd>       the working directory. defaults to the current
                        directory. (default: "/home/you/my-app")
  -r, --registry <url>  the registry to install components from. (default:
                        "https://pliantui.dev/r")
  -h, --help            display help for command
```

Your project needs:

- Next.js with an `app` or `src/app` folder
- a `components.json` file. If it's missing, run `npx shadcn@latest init`, then run `pliantui init` again.

Other frameworks and the Next.js Pages Router aren't supported by `init`. In these cases the command exits with an error and changes nothing.

`init` doesn't edit your pages. When it finishes, it prints the code to wrap a page with:

<include cwd lang="tsx">
  snippets/cli/init-page.tsx#page
</include>

The `surface` is the page's route pattern, such as `/orders/[id]`. `PliantRoot` and `PliantPrePaint` must receive the same `surface`. `storage={localAdapter}` keeps each user's changes in their browser. `PliantRegion` is the component `init` added: its `slots` are the parts of the page that users can rearrange, for example through the [ask panel](/docs/ai).

`PliantPrePaint` keeps a customized page from flashing its original layout before Pliant applies the user's changes.

Run `init` again at any time. It skips what is already installed, and says so when there's nothing left to do.

Pass `--yes` to skip the questions, for example in a script. Pass `--registry` to install the components from your own registry; the component files are read from `<url>/pliant-region.json`. The URL must use `http` or `https` and can't contain a query string, a fragment or credentials.
