Use the `skills` command to add Pliant's skills for coding agents to your project. A skill is a folder with a `SKILL.md` file, in the open format that Claude Code, Codex, Cursor, GitHub Copilot and other coding agents read. The agent loads a skill when your request matches its description.

```bash
npx pliantui skills add
```

The command copies the skills that come with `pliantui` into your project. Pass the names of the skills to add only those, like `npx pliantui skills add setup`.

```txt
Usage: pliantui skills add [options] [names...]

add pliantui's skills for coding agents to your project

Arguments:
  names             the skills to add. defaults to all of them.

Options:
  -y, --yes         overwrite changed skill files without asking. (default:
                    false)
  -c, --cwd <cwd>   the working directory. defaults to the current directory.
                    (default: "/home/you/my-app")
  -d, --dir <path>  the folder to put skills in. defaults to .claude/skills if
                    the project has a .claude folder, otherwise .agents/skills.
  -h, --help        display help for command
```

Skills go in `.claude/skills/<name>` when the project has a `.claude` folder, because Claude Code reads only that folder. Otherwise they go in `.agents/skills/<name>`, the folder most other coding agents read. Pass `--dir` to choose another folder: GitHub Copilot reads `.github/skills`, so use `--dir .github/skills` for it. A relative path is resolved from the working directory.

Run the command again at any time, for example after you update `pliantui`. It skips skills that are already up to date. If you changed a skill's files, it asks before it overwrites them, in an interactive terminal. In a script, pass `--yes` to overwrite them, or the command exits with an error and writes nothing. Files you added to a skill's folder are left alone.

Use `npx pliantui skills list` to see the skills that come with the package and what each one is for.

## The skills

| Skill     | Use it to                                                                                                                                                                                                                |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `setup`   | Add Pliant to a Next.js App Router app with shadcn/ui: run `init`, wrap a route in `PliantRoot` and `PliantPrePaint`, add a `PliantRegion`, make a table reshapeable, and check it works                                 |
| `tables`  | Make a data table customizable with `usePliantTable` and `pliant-data-table`: column ids and labels, the toolbar's filters, sort options and presets, what users can change and how it is saved, grouping and aggregates |
| `storage` | Choose where users' changes are stored and set up server storage: `createStorageHandler`, an `OverlayStore`, `serverAdapter`, team and org defaults, and rendering saved layers on the server                            |
