Point mode is a selection mode. The parts of the page users can change are outlined, and selecting one shows handles to drag, resize and hide it, with a small bar for asking, adjusting and resetting that part.

## Usage

Put it next to the [ask panel](/docs/components/ask-panel), with the same targets. Users reach it through the [Customize menu](/docs/concepts/customize-menu): **Adjust by hand** selects the part the menu was opened on, and from the page header it outlines every part so they can choose one.

## What users can ask

  it only picks a part and opens the ask panel on it, and it starts from its own
  **Point** button or <Kbd>Alt</Kbd>. [The ask panel](/docs/ai) can't add cards
  yet.
</Callout>

Users choose **Adjust by hand** from the Customize menu, or hold <Kbd>Alt</Kbd> (<Kbd>Option</Kbd> on a Mac), and select a part. The selected part shows:

| Control       | What it does                                                                                   |
| ------------- | ---------------------------------------------------------------------------------------------- |
| Drag handle   | Moves the part to another place among its siblings, such as the **Overdue** card to the front. |
| Resize handle | Changes how many columns the part spans in a grid.                                             |
| Hide          | Hides the part. The Customize menu's **History** and **Reset to default** bring it back.       |
| **Ask**       | Opens the ask panel on this part.                                                              |
| **Adjust**    | Opens the part's own controls, such as a table's column settings.                              |
| **Reset**     | Drops the user's changes to this part.                                                         |

A part only shows the handles its manifest allows: a card in a stack has no resize handle, and a [locked](/docs/guides/locks) part shows no handles at all.

Asking from the bar keeps the selection, so the ask is about that part alone:

| Select          | Ask                                       | What changes                                                              |
| --------------- | ----------------------------------------- | ------------------------------------------------------------------------- |
| The key metrics | add a card for this quarter's refund rate | A **Refund rate** card shows the share of this quarter's orders refunded. |
| The key metrics | show the cards in a two-column grid       | The cards sit in two columns.                                             |

The preview above offers both asks under the cards; the refund rate card, marked scripted, plays a hand-written answer.

## Rules and guardrails

- Only the targets you pass are outlined. Everything else on the page stays out of reach.
- Every change made with the handles is checked against the part's manifest before it applies, like a change from the ask panel.
- A drag, resize or hide saves for that user only, and **Reset** returns the part to their team's default or your base.
- Outlines and labels stay below a sticky header when the page sets `scroll-padding-top` to the header's height, and labels avoid covering the page's text.

## Options

| Prop      | Type                              | Description                                                                         |
| --------- | --------------------------------- | ----------------------------------------------------------------------------------- |
| `targets` | `{ id: string; label: string }[]` | The nodes users can point at, usually the ask panel's targets.                      |
| `onPick`  | `(id: string) => void`            | Called with the id of the target the user picked.                                   |
| `trigger` | `ReactElement \| null`            | An element that toggles point mode. Defaults to none; the Customize menu starts it. |

## Accessibility

- Started from the Customize menu, point mode is a modal dialog: the rest of the page is inert, and focus moves to the selected part, or to the first outline.
- <Kbd>Tab</Kbd> and the arrow keys move between outlines, and <Kbd>Enter</Kbd>
  selects. With a part selected, the arrow keys move it, <Kbd>Shift</Kbd> with
  the arrow keys resizes it, and <Kbd>Tab</Kbd> reaches the bar.
  <Kbd>Escape</Kbd> leaves and returns focus.
- On touch screens, users start it from the Customize menu in the part's or the page's header.
