## Requirements

- React 19.2 or later
- shadcn/ui with Tailwind CSS v4
- [TanStack Table](https://tanstack.com/table) 9.3.1 or later, for customizable tables

Every guide ends with the same page: a row of metric cards that users can rearrange, and a table that remembers its sort. To build the table step by step, follow [Your first customizable table](/docs/first-customizable-table).
