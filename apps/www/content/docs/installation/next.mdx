## Before you start

You need a Next.js 16 app that uses the App Router, React 19.2 or later, and [shadcn/ui](https://ui.shadcn.com/docs/installation/next) with Tailwind CSS v4. If you don't have one yet, follow shadcn's Next.js guide first.

## Make a page customizable

<Steps>

<Step>Wrap the page and make a region</Step>

Wrap the page in `PliantRoot`, and replace the element that holds your cards with `PliantRegion`. Pass each card in `slots`, keyed by an id.

<include cwd lang="tsx" meta='title="app/orders/page.tsx"'>
  snippets/installation/page.tsx#page
</include>

- `surface` names the page. Use the route pattern, so on `app/orders/[id]/page.tsx` it's `/orders/[id]` and every order page shares one layout.
- `storage={localAdapter}` keeps each user's changes in their browser. To keep them on your server, see [Storage](/docs/storage).
- `PliantPrePaint`, with the same `surface`, keeps a customized page from flashing its original layout while it loads.
- The order of the `slots` keys is the default order. Ids are kebab-case and start with a letter.

The page looks exactly as before. Users can now reorder, hide and lay out the cards.

<Step>Make a table remember its sort</Step>

Add the data table components:

```bash
npx shadcn@latest add https://pliantui.dev/r/pliant-data-table.json
```

Then pass your TanStack Table options through `usePliantTable`, with an id for the table:

<include cwd lang="tsx" meta='title="app/orders/orders-table.tsx"'>
  snippets/installation/orders-table.tsx#table
</include>

Render `OrdersTable` inside `PliantRoot`. [Your first editable table](/docs/first-editable-table) shows the columns and the rest of the table step by step.

<Step>Try it</Step>

Start your dev server and open the page. Sort the table by clicking a header, then reload. The sort comes back.

</Steps>

## Try it from the repository

The repository has a complete orders page, with metric cards, a data table and the ask panel. You need Node.js 22.22+ or 24.11+, and pnpm 10.

```bash
git clone https://github.com/pliantui/pliant.git
cd pliant
pnpm install
pnpm build:packages
PLIANT_ASK_ENABLED=1 pnpm --filter www dev
```

Open [localhost:4000/examples/orders](http://localhost:4000/examples/orders). `PLIANT_ASK_ENABLED=1` turns on an ask panel that replays recorded answers, so it needs no API key.
