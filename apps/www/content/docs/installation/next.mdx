## Try it now

The repository has a complete example: an orders page with a row of metric cards, a data table and the ask panel. You need Node.js 22.22+ or 24.11+, and pnpm 10.

```bash
git clone https://github.com/pliantui/pliant.git
cd pliant
pnpm install
pnpm build:packages
PLIANT_ASK_ENABLED=1 pnpm --filter www dev
```

`PLIANT_ASK_ENABLED=1` turns on the recorded ask panel. It replays saved answers, so it needs no API key and only answers its suggested asks.

Open [localhost:4000/examples/orders](http://localhost:4000/examples/orders). Sort the table, hide a column from the **Columns** menu and reload: the changes stay.

The rest of this guide shows setup with the published packages.

## Before you start

You need a Next.js app that uses the App Router, Next.js 16 or later, React 19.2 or later, and [shadcn/ui](https://ui.shadcn.com/docs/installation/next) with Tailwind CSS v4. If you don't have one, follow shadcn's Next.js guide first.

## Install

### Add the package

```bash
pnpm add @pliantui/react zod
```

`@pliantui/react` is the runtime: it loads each user's changes, applies them and saves new ones. `zod` is a peer dependency.

### Add the region component

```bash
pnpm dlx shadcn@latest add https://pliantui-www.pliantui-dev.workers.dev/r/pliant-region.json
```

This copies `pliant-region.tsx` into `components/pliant`. The shadcn CLI also installs the item's npm dependencies, and adds the shadcn `button` if you don't have it. The file is yours to edit, like any shadcn component.

## Make a page customizable

### Wrap the page in PliantRoot

`PliantRoot` holds the changes for one surface. Give it the page's route as its `surface`.

```tsx title="app/orders/page.tsx"
import { PliantRoot } from "@pliantui/react"
import { localAdapter } from "@pliantui/react/local"

export default function OrdersPage() {
  return (
    <PliantRoot surface="/orders" storage={localAdapter}>
      {/* your page */}
    </PliantRoot>
  )
}
```

For a dynamic route, pass the route pattern, not the URL. On `app/orders/[id]/page.tsx`, use `surface="/orders/[id]"`, so every order page shares one layout.

`storage={localAdapter}` saves each user's changes in their browser's `localStorage`. To keep them on your server, see [Storage](/docs/storage).

### Make a region editable

Replace the element that holds a group of items, such as a row of cards, with `PliantRegion`. Pass each item in `slots`, keyed by an id.

```tsx title="app/orders/page.tsx"
import { PliantRoot } from "@pliantui/react"
import { localAdapter } from "@pliantui/react/local"

import { PliantRegion } from "@/components/pliant/pliant-region"
import { StatCard } from "@/components/stat-card"

export default function OrdersPage() {
  return (
    <PliantRoot surface="/orders" storage={localAdapter}>
      <PliantRegion
        id="key-metrics"
        slots={{
          revenue: <StatCard label="Revenue" value="$48,210" />,
          orders: <StatCard label="Orders" value="1,204" />,
          overdue: <StatCard label="Overdue" value="17" />,
        }}
        className="grid grid-cols-1 gap-4 md:grid-cols-3"
      />
    </PliantRoot>
  )
}
```

The order of the keys is the default order. Ids are kebab-case and start with a letter. Give the region its spacing with `gap-*` classes: each slot sits in a `display: contents` wrapper, so `space-*` and `divide-*` won't work.

The region renders as before. Overlays can now reorder, hide and resize the cards, group them, or fold some behind a "More" button. Users make those changes through the [ask panel](/docs/ask-panel). Pliant has no manual controls for regions. See the [roadmap](/docs/roadmap).

### Make a table remember its sort

Pliant works with tables built on [TanStack Table](https://tanstack.com/table) 9.3.1 or later, such as shadcn's data table. If your app doesn't have it, run `pnpm add @tanstack/react-table`; shadcn's data table installs it already. Pass your table's options through `usePliantTable` before they reach `useTable`, with an id for the table:

```tsx title="components/orders-table.tsx"
"use client"

import { useTable } from "@tanstack/react-table"

import { usePliantTable } from "@pliantui/react/table"

// your existing TanStack v9 setup
import { columns, features, type Order } from "./columns"

export function OrdersTable({ data }: { data: Order[] }) {
  const table = useTable(
    usePliantTable({ features, data, columns }, { id: "orders-table" }) // [!code highlight]
  )

  // Render the table as before.
}
```

Render the table inside `PliantRoot`. When a user sorts it, the sort is saved to their personal layer and comes back after a reload. Column order, visibility, widths and pinning are saved the same way, from your table's own controls. Pagination and filters last for the browser tab only. To save filters too, pass `persistFilters: true` next to `id`.
