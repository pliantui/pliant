## Before you start

You need a React Router 7 app in framework mode, React 19.2 or later, and [shadcn/ui](https://ui.shadcn.com/docs/installation/react-router) with Tailwind CSS v4. If you don't have one yet, follow shadcn's React Router guide first.

## Install

<Steps>

<Step>Install the React package</Step>

```bash
npm install @pliantui/react zod
```

<Step>Add the region component</Step>

```bash
npx shadcn@latest add https://pliantui.dev/r/pliant-region.json
```

</Steps>

## Make a route customizable

In the route module, wrap the page in `PliantRoot` and render `PliantPrePaint` first inside it:

<include cwd lang="tsx" meta='title="app/routes/order.tsx"'>
  snippets/installation/route-order-page.tsx#page
</include>

- `surface` names the page. Write the route's dynamic segments in brackets: React Router's `/orders/:id` becomes `/orders/[id]`, so every order page shares one layout.
- `PliantPrePaint` takes the same `surface`. It keeps a server-rendered page from flashing its original layout before the user's changes apply.
- `storage={localAdapter}` keeps each user's changes in their browser. To keep them on your server, see [Storage](/docs/storage).

## What works differently

- `pliantui init`, `scan` and `doctor` read Next.js projects. In a React Router app, install by hand as shown on this page.
- The ask panel and storage routes are standard web handlers: export them from a resource route's `action` and `loader`.
